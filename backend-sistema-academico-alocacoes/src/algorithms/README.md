# Algoritmos — Guia das variáveis de ambiente


## Algoritmo Genético — Parâmetros
- **GA_POPULATION_SIZE**: tamanho da população.
- **GA_GENERATIONS**: máximo de gerações.
- **GA_MIN_GENERATIONS**: mínimo de gerações.
- **GA_PATIENCE**: gerações sem melhora.
- **GA_FITNESS_TARGET**: meta de fitness.
- **GA_MUTATION_RATE**: taxa de mutação.
- **GA_CROSSOVER_RATE**: taxa de crossover.
- **GA_ELITISM_RATE**: percentual de elite.

## Penalidades e bonificações
- **GA_HARD_PENALTY_MULTIPLIER**: peso das hard.
- **GA_SOFT_MULTIPLIER**: peso das soft.
